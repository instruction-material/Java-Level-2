# Reading and Writing Files

Compile and run from this folder with Java 21.

```sh
javac --release 21 Main.java
java Main
```

The first file begins with a count and stores one integer per line. The second begins with row and column counts and stores one row of integers per line. The console shows both decoded arrays. The finishing write creates `output.out` with one line containing `test`.

Change `-3` in `in1.in` to `-4` and rerun. Only the first array changes. Restore the sample before sharing the folder.
