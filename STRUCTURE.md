# Java-Level-2 Structure

This repository backs `Java Level 2` plus selected Java with/without Graphics
cross-links. It is primarily a legacy direct-source bank with some generated
supplemental folders.

Active public folders stay at the repository top level. Folders not linked by
the live catalog on 2026-05-14 were moved to `_archived-unlinked/`.

New material should not add extra `Starter`, `Updated`, or alternate-project
folders beside the active course surface unless the live catalog links them in
the same change.
